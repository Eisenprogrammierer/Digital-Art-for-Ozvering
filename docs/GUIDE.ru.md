генераторе 2-D графики из этого репозитория. Здесь есть браузерная студия, командная
строка, все семейства ассетов, модель сидов, полная сборка, лицензии и типичные

## Что делает проект

Каждый ассет вычисляется из сида и небольшого набора параметров:

```
ассет = f(seed, параметры) -> PNG + JSON sidecar
```

Ничего не нарисовано руками, не обведено, не скачано и не сгенерировано моделью
изображений. Результат можно использовать в своих проектах по лицензии MIT, а
sidecar хранит функцию, сид и параметры, поэтому любую картинку можно пересобрать
или проверить.

Семейства:

- **Персонажи** — спрайт-листы фигур, портреты, листы портретов, lineage.
- **Геральдика** — гербы, флаги, анимации флагов, листы фракций.
- **Мир** — стратегические гекс-карты, данные кампании, крупные планы (site),
  изометрические доски.
- **Материалы** — ground-материалы, тайловые текстуры, базовый лист материалов.
- **Интерфейс** — иконки и атласы, nine-slice UI-киты, сгенерированный шрифт.
- **Ядро** — палитры и справочный лист SDF.

Выход — обычные файлы: PNG, JSON, SVG. Никакого рантайма, редактора или PROJECT-файла.
Игра загружает PNG и таблицу из sidecar.

## Установка

Нужны Python **3.10+**, `numpy`, `Pillow`. Студия использует только стандартную
библиотеку поверх этого.

```bash
git clone <этот репозиторий>
cd Digital-Art-for-Ozvering
python -m pip install -r requirements.txt
```

Проверка без рисования:

```bash
python cli.py --help
python cli.py figures --help
```

Локальная среда, в которой собран проверенный билд: Python 3.14, numpy 2.5,
Pillow 12. CI дополнительно проверяет 3.10 и 3.13.

## Быстрый старт

### Один ассет в браузере

```bash
python cli.py studio --port 8000
```

Команда печатает `http://127.0.0.1:8000/` и открывает страницу. Выберите ассет,
задайте сид, нажмите **Generate**. Появятся картинка, файлы, sidecar, команда и zip.

### Вся демо-сборка

```bash
python cli.py demo --out out --seed 7
```

Занимает примерно 3–4 минуты и пишет полную галерею, все листы, экран авторов и
`out/index.html`. Откройте `out/index.html` в браузере.

### Один лист из терминала

```bash
python cli.py figures --out out/figures.png --seed 7 --cycle walk --count 8
python cli.py iso     --out out/iso.png     --seed 7 --cols 11 --rows 8 --size 46
```

Каждая команда пишет PNG и `.json` рядом с ним.

## Студия

`studio/` — небольшая локальная веб-страница над командной строкой. Это основное
место для экспериментов: результат, файлы и точная команда видны в одном окне.

### Запуск и параметры

```bash
python cli.py studio                     # 127.0.0.1:8000, откроет браузер
python cli.py studio --port 0            # свободный порт выберет ОС
python cli.py studio --root assets/work  # писать в другую папку
python cli.py studio --no-browser        # не открывать окно
```

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `--host` | `127.0.0.1` | Интерфейс. Не меняйте без необходимости. |
| `--port` | `8000` | `0` — попросить свободный порт; в выводе будет настоящий. |
| `--root` | `out/studio` | Куда писать рендеры. |
| `--no-browser` | выкл. | Не вызывать `webbrowser.open`. |

Студия — рабочий стол для одного человека на одной машине. В ней нет авторизации и
загрузки файлов. Не открывайте `0.0.0.0` в недоверенной сети.

### Страница

1. **What to make** — выберите генератор; они сгруппированы по семействам.
2. **Форма** — каждое поле соответствует флагу CLI. Числа ограничены диапазоном,
   варианты закрыты, необязательные поля помечены.
3. **Generate** — запускает настоящую команду. Первый рендер включает запуск Python
   (около двух секунд); тяжёлые ассеты дольше.
4. **Картинка** — основной результат на шахматном фоне, чтобы видеть прозрачность.
5. **This result** — все файлы с размерами и ссылками, `bundle.zip`, sidecar в JSON
   и команда, которая это воспроизводит.
6. **New seed** — случайный сид для текущей формы. Сам по себе не генерирует.

`Ctrl+Enter` / `Cmd+Enter` запускает генерацию. Команду из результата можно
скопировать и вернуться с ней в терминал.

### Куда попадают файлы

У каждого рендера своя папка с токеном:

```
out/studio/20261020-201325-1a2b3c/
  iso.png
  iso.json
  bundle.zip          # создаётся по запросу
```

Токен — отметка времени плюс шесть случайных hex-цифр, поэтому одинаковые имена
файлов не перезаписывают друг друга. Это обычная папка: копируйте PNG и JSON в
проект игры или удаляйте. При старте студия чистит папки старше семи дней и
оставляет не больше двухсот последних.

## Сиды, размеры и воспроизводимость

**Сид** — это идентичность ассета. Одинаковый сид и параметры дают одинаковые
пиксели и одинаковый sidecar в одинаковой среде. Изменение одного числа даёт другой
ассет, а не «вариант того же».

- Сид — неотрицательное целое. `0` допустим.
- Лист независимых ассетов берёт базовый сид и прибавляет индекс; sidecar хранит
  сид или геном каждой ячейки.
- У некоторых генераторов есть свой сид: например, `--hero-seed` у доски сохраняет
  одного героя при смене карты.
- Размер — это размер вывода, а не ресемпл. Иконка 512 px *рисуется* в 512 px из
  той же геометрии; поэтому толщина линии и фаска заданы в пикселях.
- `--count` и `--cols` управляют числом ячеек и переносом строк.
- Воспроизводимость точная в одной среде Python/numpy/Pillow. Если нужен
  байт-в-байт результат для поставки, зафиксируйте версии: сглаживание и цветовые
  преобразования могут меняться между крупными версиями библиотек.

Рядом с каждой картинкой экспортёр пишет JSON sidecar:

- `source` — модуль, нарисовавший ассет, например `procedural:gen.maps.iso`;
- сид и параметры;
- для карт — провинции, реки, дороги, государства и отдельный файл кампании;
- для листов — прямоугольники ячеек, таймлайн и спецификации по ячейкам;
- для шрифта — метрики и нарисованные символы;
- для доски — камера, террасы, параметры материала и направление героя;
- для листа фигур — цикл, направление, таблица кадров и геном тела.

Sidecar — это происхождение ассета. Храните его вместе с PNG: проверка лицензий
читает именно его.

## Семейства ассетов

### Фигуры

Фигура — одно тело в последовательности фаз, а не набор отдельных рисунков. Циклы:
`idle`, `walk`, `run`, `attack`; `attack` — одноразовое действие внутри цикла, чтобы
игра проиграла его один раз и вернулась в idle.

```bash
python cli.py figures --out out/figures.png --seed 7 --cycle walk --count 8
python cli.py figures --out out/figures.png --seed 7 --cycle walk --facing down
```

Дальняя конечность в профиле — подсказка глубины; в видах спереди и сзади видны обе
конечности, и тёмное/светлое разделение не используется.

### Портреты

Портрет — голова как стопка сечений с прослеживаемым геномом, который можно
смешивать и скрещивать. `portrait` рисует один, `portraits` — лист, `lineage` — двух
родителей и детей. Стиль, волосы, выражение и демографические гены можно задать
вручную, не меняя остальные.

```bash
python cli.py portrait --out out/one.png --seed 5 --size 384
python cli.py portrait --out out/elder.png --seed 5 --age elder --climate arid
python cli.py portraits --out out/portraits.png --seed 7 --count 8 --size 256
python cli.py portraits --out out/women.png --seed 7 --sex female --count 8
python cli.py portrait --out out/heart.png --seed 7 --face-shape heart \
                        --eye-shape hooded --nose-shape roman --freckles bridge
python cli.py portrait --out out/pigment.png --seed 7 \
                        --gene skin_melanin=-0.4 --gene hair_warmth=0.6
python cli.py lineage --out out/lineage.png --seed 7 --children 6
```

`sex`, `age`, `climate` и `culture` — такие же гены, как остальные. `sex` меняет
презентацию и некоторые пропорции; `age` задаёт возрастную стадию, седину в цветовом
скрипте и возрастные детали; `climate` — среда, к которой приспособлена линия, поэтому
он сдвигает диапазоны кожи и черт, а не рисует костюм; `culture` выбирает традицию
одежды — воротник, отделку и застёжку — и никогда не лицо. `portraits` принимает те же
четыре флага, чтобы закрепить один ген на всём листе.

Фенотипический слой добавляет именованные семейства и непрерывные оси. Семейства:
`--face-shape` (oval, round, square, heart, long, diamond), `--jaw-shape`,
`--eye-shape`, `--brow-shape`, `--nose-shape`, `--mouth-shape`,
`--hairline-shape` и `--freckles`. Непрерывные оси — ширина и высота лба, ширина
висков, ширина и посадка скул, полнота щёк, угол и ширина челюсти, длина и ширина
подбородка, глубина головы, расстояние между глазами, высота и нависание века,
размер радужки, высота и длина бровей, длина/ширина/переносица носа, высота рта,
полнота губ, размер ушей, ширина и длина шеи, высота линии роста волос, объём
волос, длина и пробор чёлки, вес боковых прядей и наклон плеч. Двенадцать
пигментных осей двигают меланин/тепло/розовость/оливковость кожи,
меланин/тепло/рыжину/блеск волос, оттенок/насыщенность/светлоту радужки и пигмент
губ. У каждой оси диапазон `[-1, 1]` и нейтральный ноль; категории выбираются из
таблицы.

`--gene KEY=VALUE` закрепляет любую ось генома, включая старые гены формы и цвета;
повторите флаг для нескольких. Строка ДНК, записанная до появления фенотипических
генов, всё ещё читается: отсутствующие демографические и фенотипические гены
получают документированные значения по умолчанию, а пропущенный ген формы или
цвета — ошибка. Новые гены дописываются в конец формата, а не вставляются, поэтому
порядок сохранённой династии не меняется.

### Геральдика

Герб — это спецификация: щит, поле, деление, фигуры и тинктуры. Фракция — имя,
хешированное в герб, баннер и ливрею; имя является входом, а не сид. Флаг — это
полотно: полосы проекцией, складки как смещение нормали, древко и полотнище.
Анимация — тот же флаг, дискретизированный по своему `t`.

```bash
python cli.py arms --out out/arms.png --seed 7 --count 12
python cli.py flags --out out/flags.png --seed 7 --count 12 --ratio 3:2 --hang bar
python cli.py anim --out out/anim.png --seed 7 --count 12 --fps 12
python cli.py factions --out out/factions.png --name "Kingdom of Alder" \
                        --name "The Salt League"
python cli.py blazon --out out/one.png --seed 5
```

`blazon` печатает текстовое блазонирование и рисует герб, чтобы описание и картинку
можно было сравнить.

### Карты

`maps` рисует стратегический вид: рельеф, берег, реки, дороги, провинции,
государства, имена и JSON кампании.

```bash
python cli.py maps --out out/maps.png --seed 7 --count 1 --cols 26 --rows 17 \
                    --sea 0.42 --provinces 8 --factions 4
python cli.py maps --out out/maps.png --seed 7 --no-names
```

Для каждой карты демо также пишет `out/maps.campaign.<seed>.json`: карту как данные,
а не пиксели. Именно этот файл загружает игра без генератора.

### Sites и доски

`site` — камера вниз: тот же тип местности, но субъект — земля. По умолчанию две
панели: цвет биома слева и материал справа, с вырезанной рекой, обрывами и мокрым
берегом. `--flat` оставляет только цветную панель.

```bash
python cli.py site --out out/site.png --seed 7 --size 56 --cols 8 --rows 6
python cli.py site --out out/site.png --seed 7 --size 56 --river-fraction 0.90
```

`iso` — доска с юга: террасированные гекс-призмы, топы с материалом в мировых
координатах, земляные обрывы, пена и фигура. Рисуются только южные грани, ряды — от
дальних к ближним, герой вставляется после своего ряда.

```bash
python cli.py iso --out out/iso.png --seed 7 --cols 11 --rows 8 --size 46
python cli.py iso --out out/iso.png --seed 7 --cols 11 --rows 8 --size 46 \
                   --hero 3,5 --facing down
```

`--hero` — это `row,col`. Гекс должен быть внутри сетки и на земле; неверный гекс
останавливает команду с сообщением и без файла. `--hero-seed` сохраняет фигуру
независимой от сида карты. `--levels` — число террас, `--rise` — преувеличение
высоты, `--sea` — доля моря.

**Известное ограничение, честно:** `maps`, `site` и `iso` генерируют свою географию
для того размера сетки, который вы попросили. `terrain.fields` нормализует по
размеру сетки, поэтому site или доска 8×6 при том же сиде — не вырезка из
стратегической карты 26×17, а другой остров того же типа. Режим окна/кропа не
реализован. Если нужна конкретная местность в игре, генерируйте стратегическую карту
и её campaign-файл, а site/board считайте отдельной иллюстрацией; либо используйте
один сид и форму для семейства картинок, понимая, что это родственники, а не
вырезки.

### Берег и тайлы границ

`coast` превращает край карты в ассет: все шестьдесят четыре комбинации шести сторон
гекса, панель границ биомов и подсчёт того, сколько тайлов реально используют
демо-карты. Игра блитит тайл по ключу края, а не обходит polyline. Сам лист не зависит
от сида; сид выбирает только карты для подсчёта.

```bash
python cli.py coast --out out/coast-tiles.png --size 20 --count 2
```

Команда также пишет `borders.png` — одну карту с внутренней границей биомов и без неё,
чтобы была видна разница, которую даёт этот слой.

### Материалы

`grounds` рисует шесть ground-материалов одним painter'ом и таблицей из пятнадцати
полей на строку. `tiles` — Truchet, Wang, Gray-Scott и доски с измеренной ошибкой
шва. `texture` — базовый лист fBm/мрамор/дерево/камень.

```bash
python cli.py grounds --out out/grounds.png --seed 7 --size 256
python cli.py tiles --out out/tiles.png --seed 7 --size 256
python cli.py tiles --out out/tiles.png --seed 7 --size 256 --mips 4
python cli.py texture --out out/texture.png --seed 3 --size 256
```

`--mips N` пишет лист на каждый mip-уровень и пакует каждый уровень отдельно.
`--no-atlas` пропускает атлас, если нужен только лист.

### Иконки и UI

Иконка — это плита с фигурой, бейдж количества или уровня и ливрея фракции на плите.
Команда пишет набор, размеры, атлас и sidecar с прямоугольниками.

```bash
python cli.py icons --out out/icons.png --seed 3 --count 8 --size 192 \
                    --sizes 32,64,128 --cols 9
python cli.py icons --out out/icons.png --seed 3 --count 8 --name "Kingdom of Alder"
```

UI-киты — nine-slice рамки: ассет — это `(PNG, вставки углов, минимальный размер)`, а
не просто картинка. `--svg` дополнительно пишет каждый кит кривыми.

```bash
python cli.py ui --out out/ui.png --seed 7 --count 3 --scale 2
python cli.py ui --out out/ui.png --seed 7 --count 3 --scale 2 --svg
```

### Шрифт

Шрифт генерируется из скелетов и пера: 214 символов, пять начертаний, метрики,
кернинг и пять лигатур. Это не системный шрифт, файл шрифта не нужен.

```bash
python cli.py text --out out/text.png --size 20
python cli.py text --out out/text.png --size 20 --face text
```

Актуальные имена начертаний — в `python cli.py text --help`.

### Ядро

`palette` рисует сидовый набор OKLCH-свотчей в sRGB. `shapes` — справочный лист SDF:
примитивы, которыми рисует всё остальное.

```bash
python cli.py palette --out out/palette.png --seed 3 --count 6
python cli.py shapes --out out/shapes.png
```

## Четыре направления героя

`figures` и `iso` принимают `--facing`:

| Значение | Что значит | Как нарисовано |
| --- | --- | --- |
| `right` | вправо по экрану, `+x` | профиль, как раньше |
| `left` | влево по экрану, `-x` | готовый правый спрайт, точно отражённый |
| `down` | к камере (юг) | вид спереди: тот же скелет, конечности разведены по сторонам, шире грудь, голова без носа и с шапкой волос |
| `up` | от камеры (север) | вид сзади: то же тело, голова полностью в волосах, без лица |

`up` и `down` — не поворот профиля и не второе тело. Это те же суставы, поставленные
анфас; поэтому у четырёх направлений одни пропорции, одна палитра и одна походка.
Направление записывается в sidecar, так что лист или доску можно пересобрать.

По умолчанию у доски `right`, поэтому старые команды дают те же байты. Отражение
точное: `left` — это `right`, перевёрнутый после рисования, вместе с альфой и цветом.

## Карты, сайты и доски

Три вида мира — это три разные камеры:

- **`maps`** — стратегический вид, один растровый проход, около 14 пикселей на гекс.
  Это информация: биом, владелец, дороги, имена.
- **`site`** — крупный план, где гекс достаточно велик, чтобы спросить, из чего он
  сделан. Материал семплируется в мировых координатах и освещается один раз вместе с
  высотой; море маскируется точно. Реки вырезаны в поле высот; обрывы и мокрый берег —
  накладки только на земле.
- **`iso`** — доска, на которую смотрит игрок. Орфографическая аксонометрия с юга,
  террасированные призмы, только южные грани, ряды от дальних к ближним, фигура
  вставляется в свой ряд. Камера фиксирована намеренно; у фигуры четыре билборда, а
  не свободный поворот.

Проекция:

```
screen_x = x
screen_y = -y * squash - height * rise
```

`--rise` преувеличивает высоту, потому что реальный рельеф на этом масштабе был бы
всего несколько пикселей. `--levels` задаёт число террас: больше уровней — больше
мелких ступеней.

## Полная сборка

```bash
python cli.py demo --out out --seed 7
```

Демо пишет все листы и sidecar, coast/border-тайлы, grounds и атласы, site и доску,
образец шрифта, фракции, экран авторов и `out/index.html`. Занимает примерно 3–4
минуты и намеренно выполняется одним процессом; не запускайте две демо-сборки
одновременно.

Релиз проверяется, а не предполагается:

```bash
python -m pyflakes cli.py core gen export studio tests
python tests/test_core.py
python tests/test_heraldry.py
python tests/test_portraits.py
python tests/test_ui.py
python tests/test_maps.py
python tests/test_textures.py
python tests/test_cli.py
python tests/test_icons.py
python tests/test_text.py
python tests/test_figures.py
python tests/test_gallery.py
python tests/test_studio.py
python cli.py credits --manifest out --check
python cli.py gallery --manifest out --stats
```

Тестам не нужен `pytest`; каждый файл запускается как скрипт и печатает `n/n passed`.
`pytest` тоже работает. Детерминизм проверяется двумя сборками:

```bash
python cli.py demo --out /tmp/build-a --seed 7
python cli.py demo --out /tmp/build-b --seed 7
diff -r /tmp/build-a /tmp/build-b
```

Если деревья совпадают байт в байт, сборка детерминирована.

## Авторы и лицензии

Код — MIT. Сгенерированные PNG не несут сторонних прав; храните сид и sidecar, чтобы
их можно было пересобрать.

Единственный внешний ассет — музыка **Kevin MacLeod** под **CC BY**. Указание
авторства обязательно при поставке. Репозиторий хранит атрибуцию в `core/credits.py`
и копирует её в каждую сборку:

```bash
python cli.py credits --manifest out          # что мы должны
python cli.py credits --manifest out --out out  # записать out/credits.txt
python cli.py credits --manifest out --png out/credits.png
python cli.py credits --manifest out --check  # код 0 только если сборку можно ship'ить
```

`--check` сообщает, но не исправляет. Он падает, если:

- у curated-источника нет обязательного поля (проблема кода);
- у картинки нет sidecar или sidecar ссылается на неизвестный источник (проблема
  сборки);
- обязательной атрибуции нет в credits на диске (проблема забывчивости).

Галерея тоже показывает вердикт проверки словами самой проверки. Не подделывайте
sidecar, чтобы заглушить проверку: добавьте источник или пересоберите ассет.

## Если что-то не работает

**`ModuleNotFoundError: No module named 'numpy'` / `PIL`**
Установите зависимости тем же интерпретатором, которым запускаете `cli.py`:
`python -m pip install -r requirements.txt`.

**Порт студии занят**
`python cli.py studio --port 0` (в выводе будет настоящий порт) или другой номер:
`python cli.py studio --port 8010`.

**Браузер не открылся**
Сервер работает; откройте напечатанный URL. В следующий раз добавьте `--no-browser`
и открывайте вручную.

**Рендер долгий**
Первый запрос включает запуск Python. `maps`, `site`, `iso`, `grounds`, `tiles`,
`icons` и `text` могут занимать от секунд до минуты. Студия выполняет рендеры
последовательно, поэтому второй запрос ждёт, а не конкурирует. Статусная строка
показывает, что происходит.

**`iso: the hero's hex ... is water`**
Указанный гекс должен быть землёй. Уберите `--hero`, чтобы доска выбрала ближайшую
равнину к центру, или выберите землю. Гекс вне сетки отклоняется так же, с
сообщением, а не traceback.

**`iso: the hero's hex ... is off a ROWSxCOLS map`**
Гекс вне сетки; строки и столбцы нумеруются с нуля и идут в порядке `row,col`.

**Ссылки в галерее битые**
Пересоберите её из папки сборки: `python cli.py gallery --manifest out`. Если HTML
перенесли без картинок, соберите встроенную версию:
`python cli.py gallery --manifest out --embed`.

**`credits --check` падает после добавления картинки**
Картинке нужен sidecar и известный источник. Пересоберите её через CLI, а не
копируйте PNG в `out/`: экспортёр пишет sidecar. Если это curated-ассет, добавьте его
в `core/credits.py` с обязательными полями.

**Site/board не похож на мою стратегическую карту**
Это отдельные географии для запрошенного размера сетки, а не вырезки. См.
[Карты, сайты и доски](#карты-сайты-и-доски). Для реальных данных стратегической
карты используйте campaign JSON.

**На другой машине результат не байт-в-байт**
Зафиксируйте Python, numpy и Pillow. Детали плавающей точки и сглаживания могут
меняться между версиями библиотек, даже если алгоритм не менялся.

**Старая ссылка на скачивание в студии пропала**
Стартовая очистка удаляет папки старше семи дней и всё сверх двухсот последних.
Сгенерируйте заново: каждый рендер воспроизводится командой и сидом.
