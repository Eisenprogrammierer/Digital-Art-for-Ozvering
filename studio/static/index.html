How this works

      

        The studio is a form over cli.py. It runs the same command a
        terminal would, writes the files under out/studio/<token>/,
        and shows you the command so the result can leave the browser and become a
        script. Same form, same seed, same bytes.
      

      

        Slow ones (maps, sites, boards, materials) can take a few seconds; the
        status line says when it is working. Everything is generated locally; no
        request leaves this machine.
